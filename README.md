# Kanepe Altı Kumanda Avcısı

> Türkiye Cumhuriyeti Kanepe Bakanlığı tarafından onaylanmış,
> yastık mühendisliği disiplinine uygun,
> bilimsel olarak şüpheli ama duygusal olarak zorunlu yazılım.

## Bu proje ne yapar?

Televizyon açıktır. Dizi gelmiştir. Kumanda yoktur.
Aile meclisi toplanır. Suçlamalar başlar.
Bu yazılım o anda devreye girer ve kanepeyi **resmî törenle** arar.

Çalışır. Gerçekten. Python 3 yeter.

```bash
python3 avci.py
python3 avci.py 5
```

Sayı, yastık kaldırma turunu belirler. 9'dan fazla tur kabul edilmez.
Çünkü onuncu turda ilişkiler bozulur.

## Bilimsel yöntem

1. Sol köşe yastık kaldırılır.
2. Sağ köşe yastık kaldırılır.
3. Ortadaki süslü yastık — dokunulmazlık kalkar.
4. Misafir yastığına el konulur.
5. Kedi tüyü arşivi incelenir.

Sonuç dört hâlden biridir:

- **bulundu** — evde bayram ilan edilir
- **yarim** — sadece pil kapağı çıkar
- **hayir** — 2014 faturası bulunur
- **efsane** — kumanda var, pil yok

## Neden bu kadar ciddi?

Çünkü kayıp kumanda ev içi güvenlik sorunudur.
Çünkü kanepe bir mobilya değil, arşivdir.
Çünkü herkes "az önce buradaydı" der ve kimse kanıt sunmaz.

## Kurulum

Kurulum yoktur. İndir, çalıştır, yastığı kaldır.

## Katkı

Pull request atmadan önce evdeki kanepeyi en az bir kez resmi olarak arayın.
Aksi hâlde PR reddedilir. Gerekçe: saha tecrübesi yok.
